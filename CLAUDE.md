## Проверено на этой базе (этап 1)

- **Безопасный режим расширения запрещает HTTP** («Установлен безопасный режим. Выполнение операции
  запрещено» на `HTTPСоединение`). В учебной платформе нет `ibcmd`, навык `db-cfe-admin set-properties` не
  работает. Снимать в самой 1С: Shift+F11 → `e1cib/app/ОбщаяФорма.Расширения` → снять флажок в колонке
  «Безопасный режим» (щит) → «перезапустить». После `load.bat` настройка сохраняется.
- **Учебная 8.5 ходит по HTTP на localhost** — `HTTPСоединение` к `http://localhost:8000` работает.
- **Запуск клиента:** `1cv8ct.exe ENTERPRISE /F C:\1c\unf_ucheb /NАдминистратор`. Окно стартует свёрнутым,
  для управления с компьютера — развернуть через WinAPI (`ShowWindow`/`SetForegroundWindow`). При первом входе
  БСП спрашивает «перемещена или копия» — ответ «Это копия информационной базы».
- **В демо-базе предопределённый вид цен `Оптовая` переименован в «Розничная».** Виды цен искать по
  наименованию; розница и опт должны быть разными элементами (`хт_ДемоДанные.ВидЦен`).
- **В демо-УНФ уже есть группа «Сантехника»** с двумя товарами без цены — они попадают в выгрузку.
- **Псевдоним таблицы не должен совпадать с именем поля присоединённых таблиц:** `Справочник.Номенклатура
  КАК Номенклатура` + соединение с регистром, где есть поле `Номенклатура` → «Неоднозначное поле
  Номенклатура.ЭтоГруппа» (ошибка только при выполнении, `/CheckModules` её не видит).
- **Демо-данные:** команда «Заполнить демо-каталог Хозтрейд» (раздел «Сайт»), макет `хт_ДемоКаталог`
  генерируется из `site/catalog/demo_data.py`. Повторный запуск не дублирует.

## Проверено на этой базе (этап 2: заказы и лиды)

- **Заполнение заказа как в штатной интеграции:** `Документ.Заполнить(Новый Структура("Контрагент", ...))` — УНФ сама
  подставляет организацию, договор по умолчанию, валюту и вид цен (`ЗаполнениеОбъектовУНФ.РазыменоватьПоля`). Новый
  контрагент при записи сам получает основной договор.
- **Способ доставки «Курьер» требует** `СлужбаДоставки` и `НоменклатураДоставки`, иначе заказ не проводится. Служба —
  предопределённая `ДоставкаСобственнымиСилами`, услуга «Доставка грузотакси» (артикул `ДОСТ-ГТ`) создаётся при загрузке.
- **Состояния заказов в демо-базе:** Обсуждение КП, В производстве, Выезд замерщика, Разработка дизайн-проекта,
  На складе, Выполнен, Завершен. По умолчанию УНФ ставит «В производстве» — заказам с сайта ставим «Обсуждение КП».
- **Автоскидка 5 % при проведении** (правило демо-базы, срабатывает от суммы заказа) — сумма в 1С меньше суммы на
  сайте. Не отключаем: итог из 1С уходит на сайт со статусом (`total`), покупатель видит скидку.
- **Лид:** `Лид.Заполнить(Неопределено)` заполняет состояние, ответственного, вид. Телефон/email — через
  `УправлениеКонтактнойИнформацией.ДобавитьКонтактнуюИнформацию` с видами `ТелефонКомпанииЛида`/`EmailКомпанииЛида`;
  файл — `РаботаСФайлами.ПараметрыДобавленияФайла` + `ДобавитьФайл`.
- **Открыть список в клиенте:** Shift+F11 → `e1cib/list/Документ.ЗаказПокупателя`, `e1cib/list/Справочник.Лиды`.

## Проверено на этой базе (этап 3)

- **Регламентные задания в учебной файловой 8.5 работают**, пока открыт клиент 1С: задание расширения
  `хт_ОбменССайтом` (расписание `Ext/Schedule.xml`, `RepeatPeriodInDay=300`) забирало заказы через 3–5 минут
  после запуска клиента. Расширение может содержать своё регламентное задание.
- **Безопасное хранилище БСП** (`ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище`, владелец — ссылка на
  настройку) работает из расширения в привилегированном режиме, в том числе в сеансе регламентного задания.
  Перенос реквизита в хранилище — в две загрузки: сначала код с переносом при чтении, потом удаление реквизита.
- **Без формы XML:** ввод значения — общая команда с параметром `CatalogRef.X`, группа
  `FormCommandBarImportant`, `ПоказатьВводСтроки` на клиенте. Команда появляется в автоформе элемента.
- **Картинки в макете:** двоичный макет (`Template.bin`) — контейнер 1С, не сырой файл. Проще текстовый макет
  с JSON и base64 (`Base64Значение`); генератор — `1c/tools/make_demo_images.py`.
- **Присоединённый файл к номенклатуре:** `РаботаСФайлами.ДобавитьФайл` возвращает ссылку → `ФайлКартинки`;
  данные — `РаботаСФайлами.ДвоичныеДанныеФайла`.
- **Команда «Заполнить демо-каталог»** выполняется ~1 минуту (перепроведение оприходования) — ждать окна итога.
- После правок моделей сайта — `manage.py migrate` на рабочей базе сайта, иначе API обмена отвечает 500.

## Проверено на этой базе (этап 4: доставка, рейсы, отчёты)

- **Маршрутные листы в демо-базе выключены** (константа/ФО `ИспользоватьМаршрутныеЛисты`): список листов пустой,
  а СКД-отчёт по `Документ.МаршрутныйЛист` молча выдаёт пустой результат (поля объектов под выключенной ФО
  недоступны). Включает «Заполнить демо-каталог»; планирование предупреждает в сводке.
- **Проведение маршрутного листа требует курьера** (`ФизическиеЛица`), даже при «Доставке собственными силами».
  Проведение ставит заказам состояние из вида заказа (`СостояниеОтгружен`; в демо-базе — «На складе»), а заказы,
  убранные из листа при записи, получают `СостояниеОжидаетОтгрузки`.
- **Вес и объём шапки заказа УНФ считает только при заполнении документа** (`РассчитатьОбъемИВесЗаказа`), не при
  записи. При загрузке заказа заполнять `Запасы.Вес/Объем` и шапку самим; в запросах по старым заказам — считать
  по строкам (`Количество × Коэффициент единицы × Номенклатура.Вес`).
- **Отчёты расширения в УНФ открываются штатной формой отчётов БСП** (в отличие от учебной БП) — своя форма не нужна.
- **СКД: итог по формуле выводится без формата** (54,5666…) — задавать `Формат` в оформлении вычисляемого поля.
- **Подсистема расширения может включать заимствованные объекты.** Подчинённый справочник `ЗоныТарифыДоставки`
  в панели раздела не показывается — зоны открываются из выбора в тарифах.
- **Лимит 2000 записей не мешает** 299 товарам с двумя ценами и оприходованием одной строкой на товар.
- **Скрипты навыков 1c-skills** запускать с `powershell.exe -ExecutionPolicy Bypass` — иначе политика запрещает.
- **Управление клиентом с компьютера:** доступ запрашивать на `1cv8ct.exe` (путь `...\1c\8.5.1.1150\bin`), ярлык
  «1С Предприятие (тонкий клиент)» указывает на другую установку. Перед `load.ps1` закрыть все модальные окна
  клиента, иначе `CloseMainWindow` не сработает.

- **Поле надписи (`LabelField`) обрезает длинный текст** многоточием даже при `HorizontalStretch` — ограничивает
  автоширина. Нужны `<AutoMaxWidth>false</AutoMaxWidth>` (сразу после `TitleLocation`) и `<Height>2</Height>`.
- **Двойной клик в таблице планирования открывает заказ** (обработчик `РейсыВыбор`), кроме колонки «Машина».
  При управлении с компьютера целиться в колонку «Машина» по свежему скриншоту, иначе ввод уйдёт в форму заказа.

## Сайт: заметки

- Файлы сайта — **LF** (`.gitattributes`: `site/** text eol=lf`). Python на Windows в текстовом режиме пишет CRLF —
  править с `newline=''` или в двоичном режиме.
- Встроенный браузер кэширует статику: после правки CSS — перезагрузка без кэша.
- **Боевой режим включает CSP** (`config/security.py`): никаких `style="…"`, `onclick=`/`onsubmit=` и встроенных
  `<script>` в шаблонах витрины — только классы и `static/js`. Тест `pages/tests.py` это проверяет. Проверять
  витрину под CSP — конфигурацией `hoztrade-prod` (run-prod на 8001), в режиме разработки заголовка нет.
- **Файлы заявок (`media/leads/`) — персональные данные**: Django раздаёт только `products|brands|posts/`,
  Caddy отвечает 404 на `/media/leads/`. Новую публичную папку media — вписать в оба места.
- **Тесты на PostgreSQL без Docker:** пакет `pgserver` (встроенный PostgreSQL 16) в отдельном venv; ошибка
  `invalid value for parameter "TimeZone": "UTC"` лечится копированием `tzdata/zoneinfo` в
  `pgserver/.../share/postgresql/timezone`. Затем `DATABASE_URL=postgres://postgres:@127.0.0.1:<порт>/postgres`.
- **Линтер:** `ruff check .` из `site/` (конфиг `site/ruff.toml`), исключения — точечные `# noqa: <код> — причина`.
- **Дерево каталога кэшируется** (`catalog/tree.py`): массовые `update()` по группам/товарам вне импорта —
  вызывать `invalidate_tree()`, сигналы сохранения сбрасывают его сами.
- **Кэш Django должен быть общим для процессов** (`CACHE_URL`): с кэшем в памяти и 3 воркерами gunicorn после
  обмена с 1С каталог на боевом сервере был пустым — сброс версии дерева видел только один воркер. Локально
  (runserver, waitress — один процесс) не воспроизводится. В compose — `filecache:///tmp/hoztrade-cache`.
