# API обмена сайта «Хозтрейд» с 1С

Обмен всегда начинает 1С: она сама обращается к сайту. Сайт к 1С не обращается.

- Базовый адрес: `http://localhost:8000/api/v1/` (в бою — адрес сайта из настроек обмена в 1С)
- Формат: JSON в UTF-8, без BOM
- Авторизация: заголовок `Authorization: Token <EXCHANGE_TOKEN>` (значение — из `site/.env` и из
  справочника «Настройки обмена с сайтом» в 1С)
- Идентификаторы объектов 1С — уникальные идентификаторы ссылок (`Ссылка.УникальныйИдентификатор()`),
  строкой в нижнем регистре. Сайт хранит их как есть и не придумывает своих для данных 1С.

Ошибки: `401` — нет или неверный токен, `400` — неверные данные (в теле `{"errors": ...}`), `5xx` — сбой сайта.

## GET /api/v1/ping/

Проверка связи и токена.

```json
{"status": "ok", "site": "Хозтрейд", "time": "2026-10-10T15:00:00+03:00"}
```

## POST /api/v1/catalog/

Загрузка каталога: группы, товары, цены, остатки. Все разделы необязательные — можно прислать
только `prices` или только `stock`. Повторная загрузка тех же данных ничего не дублирует (upsert по `id`).

```json
{
  "full": true,
  "categories": [
    {"id": "b1c0…", "parent_id": null, "name": "Стройматериалы"},
    {"id": "c2d1…", "parent_id": "b1c0…", "name": "Сухие смеси"}
  ],
  "products": [
    {"id": "a9f3…", "category_id": "c2d1…", "sku": "СМ-001",
     "name": "Штукатурка гипсовая 30 кг", "full_name": "Штукатурка гипсовая Волма Слой 30 кг",
     "unit": "шт", "weight_kg": 30.0, "volume_m3": 0.025}
  ],
  "prices": [
    {"product_id": "a9f3…", "retail": 520.00, "wholesale": 480.00}
  ],
  "stock": [
    {"product_id": "a9f3…", "quantity": 140}
  ]
}
```

| Поле | Смысл |
|---|---|
| `full` | Полная выгрузка: товары и группы, которых нет в этой посылке, снимаются с публикации (не удаляются — на них могут ссылаться заказы) |
| `parent_id` | `null` — корневая группа каталога сайта |
| `wholesale` | `null` — оптовой цены нет (вид цен «опт» не задан в настройках) |
| `quantity` | Остаток по складам из настроек обмена, сумма |

Порядок обработки на сайте: группы → товары → цены → остатки. Группа может прийти раньше родителя —
сайт связывает родителей после загрузки всех групп.

Ответ:

```json
{
  "categories": {"created": 2, "updated": 0, "unpublished": 0},
  "products": {"created": 1, "updated": 0, "unpublished": 0},
  "prices": 1,
  "stock": 1
}
```

`categories[].sort` (необязательно) — порядок раздела в меню сайта; если не передан, порядок не меняется.

## Заказы и заявки: забрать → подтвердить

1С забирает новые объекты, создаёт у себя документы и подтверждает получение. Пока подтверждения нет,
объект отдаётся снова, поэтому сбой посередине ничего не теряет. Повторная загрузка в 1С должна быть
идемпотентной (поиск по `id` сайта).

### GET /api/v1/orders/new/

До 100 заказов, ещё не подтверждённых 1С, по возрастанию `id`.

```json
{"orders": [{
  "id": 1, "number": "Х-000001", "created_at": "2026-10-10T15:25:00+03:00",
  "customer": {"type": "company", "name": "Сергей Тестов", "phone": "+79001112233", "email": "",
               "company": "ООО «СтройТест»", "inn": "2123456781"},
  "delivery": {"method": "truck", "store": "", "address": "Чебоксары, ул. Тестовая, 1",
               "date": null, "truck_t": 1.5},
  "comment": "...", "price_type": "retail", "total": 2015.0, "weight_kg": 200.0,
  "items": [{"product_id": "a9f3…", "sku": "ЦМ-500-50", "name": "Цемент М500 Д0 50 кг", "unit": "мешок",
             "quantity": 3.0, "price": 520.0, "amount": 1560.0}]
}]}
```

`customer.type`: `person` | `company`. `delivery.method`: `pickup` (тогда заполнен `store`) | `truck`.
`product_id` — ID товара 1С из выгрузки каталога (`null`, если товар был заведён на сайте вручную).
`price_type`: `retail` | `wholesale`. `wholesale` — заказ компании, которой менеджер открыл оптовые цены в личном
кабинете сайта: цены строк — из `wholesale` выгрузки каталога, в 1С заказ получает оптовый вид цен из настройки обмена.
Реквизиты такой компании (`company`, `inn`) берутся из её профиля на сайте, а не из формы заказа.

### POST /api/v1/orders/ack/

```json
{"orders": [{"id": 1, "ext_id": "<uuid ЗаказПокупателя>", "ext_number": "00ХТ-000012"}]}
```
Ответ: `{"acknowledged": 1}`.

### POST /api/v1/orders/status/

```json
{"orders": [{"id": 1, "status": "confirmed", "status_text": "В работе", "ext_number": "00ХТ-000012",
             "total": 22420.00}]}
```

`status`: `new` | `accepted` | `confirmed` | `shipping` | `done` | `canceled` — по нему сайт рисует шаги
заказа у покупателя. `status_text` — состояние заказа в 1С как есть. `total` (необязательно) — сумма
документа в 1С: учитывает скидки и акции, настроенные в учётной системе; если она меньше суммы на сайте,
покупатель видит скидку и итог по счёту. Ответ: `{"updated": 1}`.

### GET /api/v1/leads/new/ и POST /api/v1/leads/ack/

```json
{"leads": [{"id": 1, "kind": "list", "name": "Ольга", "phone": "+79002223344", "email": "",
            "text": "брус 100×100 — 30 шт…", "created_at": "…",
            "file": {"name": "smeta.pdf", "url": "http://localhost:8000/api/v1/leads/1/file/"}}]}
```

`kind`: `callback` (обратный звонок) | `list` (заказ по списку). `file` — `null` или ссылка на файл;
скачивается тем же токеном. Подтверждение — как у заказов, ключ `leads`.
